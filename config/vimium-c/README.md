# Vimium C

`settings.json` is the original Vimium C export from 23 September 2026
(extension version 2.12.2). It includes custom mappings and sync settings.

To restore, open Vimium C's extension options in your browser and import
`settings.json` using its settings import control, then save if prompted.
The dotfiles installer makes this export available at
`~/.config/vimium-c/settings.json`; the browser still needs the manual import.

To update, export your settings from Vimium C and replace `settings.json`.
